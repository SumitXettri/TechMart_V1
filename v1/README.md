## Local integration testing (Postgres + Redis + worker + socket)

Prereqs: Docker and Docker Compose installed.

- Start services: `docker compose up -d`
- Push Prisma schema: `npx prisma db push --accept-data-loss`
- Seed DB: `npm run seed`
- Start socket and worker (if not using compose): `npm run socket:dev` and `npm run worker:dev`
- Run Playwright E2E: `npm run e2e` (ensure `BASE_URL` points to your running site, default `http://localhost:3000`)

CI: A GitHub Actions workflow at `.github/workflows/e2e.yml` spins up Postgres and Redis, pushes the schema, seeds, and runs Playwright tests on push/PR.
